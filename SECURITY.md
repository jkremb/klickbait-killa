# Security

Please report security problems privately through GitHub's [private vulnerability reporting](https://github.com/jkremb/klickbait-killa/security/advisories/new), not in a public issue.

Relevant reports include anything that could expose API keys or the passphrase to web pages or other addons, let model output run as code or become links, or send data anywhere other than YouTube and the provider the user chose.

Don't include real API keys in reports.
